# Milestones

This file is the one roadmap. It holds each item, what it needs, its exit test and its status.
The order of the work and the rules are in `DESIGN.md` section 13 (D-27).
The decision IDs (D-xx) are in `DESIGN.md` section 15.

M0 and M1 are done. The M2 solver was on main ([PR 10](https://github.com/yujieteo/femahoy/pull/10)).
The owner removed the native solver `fh-solve` on 2026-10-19 (D-29). An own solver is a main advantage later, but not now. Main commit `08a97c2` has the native solver. CalculiX (`ccx`) is the only solver, and each validation case passes through it. `fh` starts `ccx` directly (D-31).
The M2 stage gates are newer than PR 10. The gate check of 2026-10-18 on main 0b11eff passed M2.1, M2.2, M2.4 and M2.5. M2.3 passed after that check ([PR 51](https://github.com/yujieteo/femahoy/pull/51)). M2.3 and M2.6 are done, and so is M2.
The owner cut the validation suite to 9 cases on 2026-10-19. Each case has 1 `C3D10` mesh, and `C3D10` is the only element (D-19). `fh check` and `fh validate --convergence` are removed.
