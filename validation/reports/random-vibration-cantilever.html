This case checks the random vibration path: a steel cantilever on a shaker with a flat base acceleration PSD. The check is the RMS acceleration of the tip. The reference is the modal sum of the beam theory, and Miles' equation is the hand check.

Why this case

No other case of the suite has any of these items:

  • A random response: a PSD of the base acceleration, and the RMS of the response.
  • *STEADY STATE DYNAMICS: the frequency response from the modes, with *MODAL DAMPING.
  • *BASE MOTION: the support moves, and the response is the absolute motion.
  • The RMS step of fh (crates/fh/src/ccx/rms.rs): ccx/rms.txt and the check field A_RMS.

Sources

  • J. W. Miles, "On structural fatigue under random loading", Journal of the Aeronautical Sciences, vol. 21, no. 11, 1954, pp. 753-762. It gives the RMS response of 1 mode to a flat PSD: Miles' equation.
  • R. D. Blevins, Formulas for Natural Frequency and Mode Shape, Van Nostrand Reinhold, New York, 1979, Table 8-1, the clamped-free beam. It gives λ_r and σ_r of the mode shapes.

The derivation below gives the reference from these 2 sources, so that a reader can check it without a book.

The beam has the length L, the bending stiffness EI and the mass per length m. The base moves with the acceleration a_b(t). The deflection w(x, t) relative to the base obeys:

EI w'''' + m w_tt = -m a_b
phi_r(x) = cosh(lam_r x / L) - cos(lam_r x / L) - sig_r (sinh(lam_r x / L) - sin(lam_r x / L))
omega_r = lam_r^2 / L^2 sqrt(EI / m)

With this scale of phi_r: the integral of phi_r^2 over the beam is L, the integral of phi_r is 2 sig_r L / lam_r, and phi_r(L) = 2 (-1)^(r+1). Each mode r with the damping ratio zeta obeys q_tt + 2 zeta omega_r q_t + omega_r^2 q = -G_r a_b, with G_r = 2 sig_r / lam_r. G_r^2 is the fraction of the mass that mode r moves (the effective modal mass).

The acceleration of the tip is the base acceleration plus the acceleration of w at x = L. For a base acceleration exp(j omega t), it is:

T(f) = 1 + omega^2 sum_r c_r / (omega_r^2 - omega^2 + 2 j zeta omega_r omega)
c_r = G_r phi_r(L) = 4 sig_r (-1)^(r+1) / lam_r,  omega = 2 pi f
A_rms^2 = integral from f1 to f2 of |T(f)|^2 W df

For r above 5, λ_r = (2r - 1) π / 2 and σ_r = 1 to 7 digits. The sum of c_r is 1: the rigid motion of the beam. This Python code integrates |T|^2 with 40 modes and Simpson's rule on 400000 intervals of log f:

import math
E, rho, b, h, L = 210000.0, 7.85e-9, 10.0, 5.0, 100.0  # SI-mm
zeta, g, W = 0.02, 9806.65, 0.04          # damping ratio, g in mm/s2, PSD in g^2/Hz
I, m = b * h**3 / 12, rho * b * h
lam = [1.87510407, 4.69409113, 7.85475744, 10.99554073, 14.13716839]
sig = [0.734095514, 1.018467319, 0.999224497, 1.000033553, 0.999998550]
lam += [(2 * r - 1) * math.pi / 2 for r in range(6, 41)]
sig += [1.0] * 35
modes = [(l * l / L**2 * math.sqrt(E * I / m), 4 * s / l * (-1) ** r)
         for r, (l, s) in enumerate(zip(lam, sig))]  # (omega_r, c_r)
def T(f):  # tip acceleration / base acceleration
    w = 2 * math.pi * f
    return 1 + w * w * sum(c / (wr * wr - w * w + 2j * zeta * wr * w) for wr, c in modes)
N, a, z = 400000, math.log(20), math.log(2000)  # Simpson's rule in log f
s = sum((1 if k in (0, N) else 4 if k % 2 else 2) * f * abs(T(f)) ** 2
        for k in range(N + 1) for f in [math.exp(a + (z - a) * k / N)])
A = math.sqrt(W * s * (z - a) / N / 3) * g
print(f"A_rms = {A:.1f} mm/s2 = {A / g:.4f} g")

It prints A_rms = 400925.4 mm/s2 = 40.8830 g: the value of the check a_tip_rms. With 5 modes the value is 0.001 % lower, and with 800000 intervals it does not change.

Miles' equation for mode 1 alone is the hand check: A_rms = c_1 sqrt(π/2 f_1 Q W) = 1.56598 x sqrt(π/2 x 417.76 x 25 x 0.04) = 40.115 g. It is 1.9 % lower than the modal sum. The modal sum also has the base acceleration below the resonance and the static part of the higher modes.
